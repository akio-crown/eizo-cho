# 映像記憶帳（仮）

写真と概念で覚え、**「使える」ようになるまで**練習する暗記帳。スマホ中心の Web アプリ（PWA）。

学習の3段階：**覚える → 使える → 応用**
- 覚える：表（単語・公式・コツ）⇄ 裏（写真・概念・意味・模範解答）を思い出す
- 使える：覚えた内容を使わないと解けない問題（誤文訂正、公式を当てはめる文章題、バグ修正、実際の場面での判断）に2回以上正解
- 応用：さらに「実生活ミッション」（実際に使う小さな行動）を1回以上達成

## 機能
- 分類は自由に何段でも：英語 › TOEIC › 英単語、数学 › 高校数学、趣味 › ダーツ など
- エビングハウスの忘却曲線に沿った復習：10分 → 1日 → 2日 → 4日 → 7日 → 15日 → 30日 → 60日 → 120日
  - 「もう一度」で2段階戻って10分後に再出題。段階2から「使える問題」に切り替わる
  - 写真や概念がある札は、裏（写真・概念）→ 表 の逆向き出題も交互に出る
- 週1回の小テスト（最近覚えた札と間違えた札から最大15問、使える問題を優先。間違えた札は復習に戻る）
- 実生活ミッション：ホームに日替わりで3つ
- Claude 連携：カードに「Claude に頼む」を付ける → 設定の「依頼文をコピー」→ Claude Code に貼る → 返ってきた JSON を貼って取り込む
  - 新しい札の一括作成も同じ形式（`path` に分類、`front` に表）
- スマホ ⇄ PC 同期（Supabase 無料枠）。未設定なら端末内（IndexedDB）だけに保存
- バックアップの書き出し・読み込み、オフライン動作

## 取り込み JSON の形
```json
[
  {
    "path": ["英語", "TOEIC", "英単語"],
    "front": "procrastinate",
    "meaning": "先延ばしにする",
    "concept": "やることを「あとで」の箱に押し込むイメージ",
    "example": "Stop procrastinating and start your report.",
    "problems": [{ "q": "誤りを直せ：I procrastinated to do my homework.", "a": "I procrastinated on my homework.", "exp": "procrastinate は自動詞" }],
    "mission": "今日の予定で後回しにしたいことを英語で1つ書く"
  }
]
```
既存の札を更新するときは `id` を入れる（依頼文に入っている id をそのまま返す）。

## 同期の準備（最初の1回だけ・あなたの作業）
1. https://supabase.com で無料アカウントを作り、New project を作る（リージョンは Tokyo）
2. 左メニュー SQL Editor に `supabase.sql` の中身を貼って Run
3. Project Settings › API（API Keys）から **Project URL** と **anon / publishable キー** をコピー
4. スマホと PC の両方で、アプリの「設定 › 同期」に貼って「保存して同期」

注意：URL とキーを知っている人は読み書きできます。キーは人に渡さず、公開するコードにも書かないでください（アプリは端末の中にだけ保存します）。

## スマホに入れる（公開先が必要）
iPhone のホーム画面に置くには https で公開する必要があります。おすすめは GitHub Pages（無料）：
1. このフォルダを GitHub のリポジトリにする（例：`eizo-cho`）
2. Settings › Pages › Branch を `main` / root にして保存
3. iPhone の Safari で `https://<ユーザー名>.github.io/eizo-cho/` を開き、共有 › ホーム画面に追加

公開されるのはアプリの画面だけで、カードの中身は公開されません（端末と Supabase にだけ保存）。

## PC で試す
```bash
cd ~/Desktop/アプリ開発/eizo-cho && python3 -m http.server 8765
```
→ http://localhost:8765

## 更新したとき
`sw.js` の `VERSION` を1つ上げると、スマホ側も新しい画面に切り替わります。

## まだないもの
- 復習のプッシュ通知（iPhone の Web アプリで通知を出すにはサーバーが必要なため保留。ホーム画面を開くと件数が出る）
- アプリ内での AI 自動生成（従量課金を避けるため、Claude Code でまとめて作る方式）

## 意味が複数ある言葉（bank＝銀行／土手 など）
意味ごとに別カードにして、表は同じ・画像、復習の間隔、使える問題は意味ごとに持たせる。
- カード編集の「＋ 別の意味を追加」で作る。一覧では1行にまとまる
- 「意味の見分けヒント」（例：名詞・お金の場面）が復習の問題文に出る。答えは書かない
- 同じ言葉の別の意味は、復習で続けて出ない
- Claude への取り込みは `senses` で：`{"front":"bank","senses":[{"hint":"…","meaning":"銀行"},{"hint":"…","meaning":"土手"}]}`

## 復習のキーボード操作（PC）
Space / Enter＝答えを見る、1〜4＝もう一度 / 難しい / 正解 / 簡単。使える問題の入力中は ⌘/Ctrl+Enter で答えを見る。
